Amiga, senta aqui um minutinho: este texto não veio trazer uma notícia urgente, uma treta geopolítica ou mais uma inteligência artificial prometendo mudar o mundo antes do café da manhã.

Ele veio fazer uma coisa bem menos glamourosa, mas absolutamente necessária: **testar se a publicação chegou direitinho ao blog**. Porque, antes de sair colocando a redação para correr atrás de grandes assuntos, a gente precisa descobrir se o post aparece, se o título fica no lugar certo e se o Markdown não resolveu criar uma personalidade própria no caminho. 😅

## O que está sendo testado?

A publicação foi criada no formato usado pelo Jekyll, com:

- título;
- data e horário;
- descrição curta;
- tags;
- texto em Markdown;
- parágrafos, negrito, itálico e lista.

Parece simples. E é justamente aí que mora o perigo: as coisas mais básicas são as primeiras a fazer drama quando ninguém está olhando.

Se você está lendo este texto no **geanramos.com**, o fluxo principal funcionou. O arquivo foi preparado para a pasta de posts do blog e enviado ao repositório que alimenta a publicação no GitHub Pages. Depois disso, o Jekyll transforma o Markdown em uma página que o navegador consegue mostrar sem fazer cara de paisagem.

Traduzindo: este é o equivalente editorial de apertar o botão da campainha e esperar alguém responder.

## Por que fazer um post de teste?

Porque publicar não é só escrever. Tem o arquivo certo, o nome certo, o front matter, a data, o build do site e a etapa de atualização do GitHub Pages. Um detalhe fora do lugar pode fazer o texto sumir, aparecer sem estilo ou simplesmente ficar esperando na fila digital.

Então este post é pequeno de propósito. Ele funciona como uma lanterninha: ilumina o caminho e mostra se está tudo em ordem antes de a gente carregar a pauta inteira pela escada.

Se alguma coisa parecer estranha, o problema já tem um suspeito: este post. E, convenhamos, é melhor descobrir agora do que depois de publicar aquele textão de 1.000 palavras e perceber que o título decidiu morar em outra dimensão.

Por enquanto, o teste é esse. Publicação criada, texto em Markdown e contexto entregue sem fingir que um arquivo de teste é a manchete do século.
